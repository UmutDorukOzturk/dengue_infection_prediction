# Dengue Infection Status Prediction

## Project Overview
This repository features an end-to-end applied statistics and machine learning pipeline designed to predict dengue infection status. Utilizing complex epidemiological and vector data, this project goes beyond raw accuracy to focus on rigorous data pre-processing, statistical evaluation, and actionable reporting.

## Methodology & Tech Stack
* **Focus Area:** Applied Statistics, Classification, Epidemiological Data Analytics
* **Language & Tools:** Python, `pandas`, `scikit-learn`, `matplotlib`/`seaborn`
* **Domain:** Public Health, Biostatistics, Predictive Modeling

## Key Challenges Solved
* **Complex Data Wrangling:** Handled extensive data pre-processing on real-world vector and epidemiological datasets to ensure statistical validity.
* **Pipeline Development:** Built a robust classification pipeline to isolate the primary statistical drivers of dengue infection.
* **Actionable Insights:** Evaluated model performance metrics and structured the outputs to serve as a foundation for a comprehensive technical report, translating raw statistical findings into understandable insights for stakeholders.

## How to View
The complete analytical workflow—from exploratory data analysis (EDA) to final model evaluation—is available in the `.ipynb` notebook within this repository.
